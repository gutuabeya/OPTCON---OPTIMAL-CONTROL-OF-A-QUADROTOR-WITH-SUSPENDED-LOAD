README.txt

The group6_OPTCON_project.zip file contains 21 files. Among these 14 are the codes we used to solve the problems.
While the files with.npz extensions are used to store the generated data by the program, so that 
another program can access the data. For example, Main_fuction.py generates xx_opt, uu_opt, xx_ref, 
and uu_ref. LQR_tracking.py as well as MPC_tracking.py use this data to try to track the generated 
trajectory.

The details of the code are as follows:
1. animation.py: code used to show the optimal trajectory as well as the animation of trajectory 
                 tracking made by LQR_tracking.
2. armijo_step_selection.py: consists of the code to select the step size, gamma, and visual of 
                 Armijo.
3. cost.py: This code consists of weight matrices of states and inputs we define. It is a user-defined 
            cost.
4. dynamics.py: consists of the dynamics of the given problem, i.e., the quadrator, in Euler 
                discretization form.
5. find_equilibruim.py: In this code, we try to find the equilibruim points for the quadrator 
                using the scipy.optimize packages.

6. LQR_tracking.py: Here the code to track the optimal trajectory is implemented.
7. MPC_tracking.py: code to stabilize the system about the optimal trajectory is implemented.
8. Main_fuction.py: This is the core of the program. Tasks such as creating the desired curve and 
                    generating the optimal trajectory is called by the main function and generated by 
                    the called function.
9. plot_trajectory.py: This is the function to plot the cost function, descent direction, optimal 
                       state,desired curve, optimal input, and desired curve.
10. referance_curve.py: function to create the smooth bell-shaped desired curve.
11. solver_ltv_LQR.py: Code from Lab. we used to compute the LQR with or without affine cost.
12. solver.py: This is also code from Lab that we used in our project. It is used as support for the 
               LQR_tracking and MPC_tracking.

13. step_referance.py: similar to referance_curve.py, It creates the desired curve, but with a step 
                       between the two equalibruims.
14. trajectory_optimazation.py: This code has the implementation of the Newton method to compute 
                        descent direction and calls armijo_step_selection.py, and update the decision 
                        variable along the descent direction by gamma factor.
